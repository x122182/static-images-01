# static-images-01

Publicly served static image assets for an internal web application.

## Usage

    https://x122182.github.io/static-images-01/<file>

Filenames are stable. When an asset changes in a way that must break caches, add a
version suffix rather than overwriting the existing file.

## Notes

- Content is public by definition of GitHub Pages. Do not put anything confidential,
  personal, or customer-identifiable here.
- Keep files optimised; this host is for artwork, not for build output.
